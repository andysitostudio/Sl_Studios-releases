## 🎯 ¿Qué es Sl Studio?

Sl Studio es una aplicación de escritorio diseñada para estudiantes chilenos que centraliza el acceso a herramientas educativas, gestiona horarios académicos y facilita la colaboración entre compañeros.

### ✨ Características Principales

#### 🚀 **Launcher de Aplicaciones**
- **Microsoft 365** (23 apps): Word, Excel, PowerPoint, Teams, OneDrive, Outlook, y más
- **Google Workspace** (19 apps): Docs, Sheets, Slides, Classroom, Meet, Drive, y más
- **Herramientas Educativas**: SchoolNet, Santillana, Common Sense, DLI
- **Asistentes IA**: Copilot 365, ChatGPT, Claude, Grok

#### 📅 **Gestión Académica**
- Horarios de clases personalizables
- Registro de pruebas y exámenes con prioridades (Alta/Media/Baja)
- Sistema de recordatorios
- Descripciones detalladas de evaluaciones

#### 👥 **Colaboración**
- Crear cursos/grupos de estudio
- Códigos únicos para unirse
- Horarios compartidos entre miembros

#### 🎨 **Personalización**
- 24+ temas de color
- Modo Oscuro / Claro
- Interfaz futurista estilo Opera GX

#### 🔒 **Seguridad**
- Contraseñas y PINs cifrados (bcrypt)
- Datos almacenados localmente (SQLite)
- Cumple con Ley 19.628 de Chile
- Sin conexión a servidores externos

#### 🔄 **Actualizaciones Automáticas**
- Sistema de actualización integrado
- Notificaciones de nuevas versiones
- Descarga e instalación automática

## 🚀 Instalación

### Para Usuarios:

1. **Descarga** el instalador desde [Releases](https://github.com/andysitostudio/Sl_Studios-releases/releases)
2. **Ejecuta** `Sl.Studio.Setup.v2.000024372.2.exe`
3. **Sigue** el asistente de instalación
4. **¡Listo!** Abre Sl Studio desde el menú inicio

### Para Desarrolladores:

```bash
# Clonar el repositorio
git clone https://github.com/andysitostudio/Sl_Studios-releases.git
cd Sl_Studios-releases

# Instalar dependencias
npm install

# Ejecutar en modo desarrollo
npm start

# Construir instalador
npm run build:win
```

## 🔄 Sistema de Actualizaciones

Sl Studio verifica automáticamente si hay actualizaciones disponibles al iniciar. También puedes verificar manualmente desde:

**Configuración → Sobre Sl Studio → Buscar Actualizaciones**

Las actualizaciones se descargan e instalan automáticamente con tu consentimiento.
